# سند · نموذج أولي تفاعلي

نموذج أولي قابل للنقر لخطة دخل شهري للمتقاعدين، مقترح لأبيان المالية ضمن تحدي صُنّاع الحلول.

## الرحلة الأساسية
كل خطوات التسجيل وإعداد الدخل فيها زر **تخطي**، وتقدر تتصفح التطبيق كاملًا بزر «تصفّح التطبيق بدون تسجيل».
1. **التسجيل**: رقم الهوية ورقم الجوال، ثم رمز تحقق تجريبي (اضغط على الإشعار لتعبئته)، ثم إنشاء رمز المرور.
2. **إعداد الدخل**: المعاش، والمبلغ المستثمر، والدخل الإضافي المطلوب، والاستقطاع الشهري (اختياري مع مبلغه)، وتقبّل المخاطر. يوم الدفعة ثابت: **27 من كل شهر**.
   - عند اختيار الدخل المطلوب: إذا ما فيه أي توزيع بحد مخاطر 10% يوصل للمبلغ خلال 12 شهر، تظهر رسالة بخط كبير: «لكي تصل للمبلغ المستهدف يجب زيادة المبلغ أو زيادة المخاطر بعد الموافقة».
   - تحت كل وصف للمخاطر تظهر أنواع الاستثمار المناسبة له (بدون أوزان).
3. **المستشار الآلي**: يختار أقل توزيع مخاطرةً يوصل للدخل المستهدف بالكامل، بحد أقصى 10% مخاطر على رأس المال (أقصى انخفاض متوقع خلال 12 شهر). لو ما قدر، يعرض أقرب دخل ممكن مع تنبيه، وتختار: تقبّل مخاطر أعلى (مع إقرار) أو تقبّل الدخل الأقرب.
4. **عرض الخطة**: رسم خطي لقيمة الاستثمار خلال 15 سنة، وتحته أوزان كل نوع استثمار، وبجانبه خيار **إعادة استثمار التوزيعات** يقارن القيمة مع وبدون إعادة الاستثمار.
5. **الإيداع وتفعيل الخطة**: بطاقة، أو تحويل بنكي، أو **السداد لاحقًا**.
6. **الرئيسية**: الدفعة القادمة، و**اقتراحات لتحسين المحفظة**، و**مقارنة مع المشابهين** (العمر والمبلغ ونوع المخاطر) برسم خطي لمحفظتك والبنش مارك.
7. **عرض الدفعات** و**تعديل الخطة**: الهدف الشهري، والأوزان، والاستقطاع الشهري، ووجهة الدفعة، وإيقافها مؤقتًا.

**صمّم خطتك بنفسك**: تختار أنواع المحافظ ووزن كل نوع (المجموع 100%)، مع نفس الرسم الخطي وخيار إعادة استثمار التوزيعات، ويتطلب إقرار مخاطر لو تجاوزت 10% أو اخترت محافظ عالية المخاطر.

**نموذج الحساب (توضيحي)**: الدخل الشهري = الرصيد × العائد المتوقع الكلي (توزيعات + نمو) ÷ 12. مخاطر المحفظة = المتوسط المرجّح لأقصى انخفاض متوقع لكل نوع خلال 12 شهر. الفئة العمرية في المقارنة مع المشابهين ثابتة (60–65) لأن التطبيق ما يسأل عن العمر.

**صكوك الشركات**: تستثمر فقط في صكوك شركات شرعية، بفرص محدودة المدة وعوائد ثابتة وتوزيعات دورية (شهرية، ربعية، نصف سنوية)، مع تفاصيل كل إصدار وجدول التوزيع القادم.

ومعها: الخدمات، وإنشاء محفظة (فيها المحفظتان الجديدتان **صكوك الشركات** و**الأسهم العقارية**)، وتفاصيل المحفظة، وحاسبة العوائد (مع خيار إعادة استثمار التوزيعات وأثره على الرسم)، وحاسبة الزكاة، وإدارة المحافظ، ودعوة صديق، والإعدادات.

**تجربة سريعة:** من شاشة البداية اضغط «تجربة سريعة بحساب أبو فيصل». رمز المرور لهذا الحساب: `111111`.

## النشر على GitHub Pages
1. ارفع محتوى المجلد إلى مستودع على GitHub (مثل `sanad-prototype`) في الفرع `main`.
2. من المستودع: **Settings** ← **Pages** ← **Source: Deploy from a branch** ← اختر `main` والمجلد `/ (root)` ثم **Save**.
3. بعد دقيقة أو دقيقتين يطلع لك رابط بصيغة `https://<اسم-المستخدم>.github.io/sanad-prototype/`.

الموقع ثابت بالكامل (HTML وCSS وJavaScript)، ولا يحتاج أي إعدادات بناء. ملف `.nojekyll` موجود حتى ينشر GitHub الملفات كما هي بدون Jekyll، والتنقل بين الشاشات يعتمد على `#` في الرابط فيشتغل من أي مسار فرعي.

## ملاحظات
- كل الأرقام والعوائد توضيحية وليست توصية استثمارية.
- لا يتم تنفيذ أي عملية مالية. بيانات الحساب والخطة تُحفظ في متصفح المستخدم فقط (localStorage).
- **التحليلات (PostHog):** ملف `analytics.js` يرسل إحصاءات استخدام مجهولة إلى PostHog (خوادم أمريكا): الشاشات، والنقرات، وأحداث الرحلة مثل `register_done` و`plan_approved` و`deposit_first`، مع تسجيل الجلسات وإخفاء كل ما يُكتب في الحقول. لإيقافها، فرّغ قيمة `POSTHOG_KEY` في `analytics.js`.
- الصفحة معلّمة `noindex` (عبر وسم meta) حتى لا تظهر في محركات البحث.
- المستودع العام على GitHub يكون ظاهرًا للجميع، حتى لو الصفحة نفسها ما تظهر في البحث.
