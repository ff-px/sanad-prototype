# سند · نموذج أولي تفاعلي

نموذج أولي قابل للنقر لخطة دخل شهري للمتقاعدين (خطة السلال الثلاث)، مقترح لأبيان المالية ضمن تحدي صُنّاع الحلول.

## الرحلة الأساسية (5 شاشات وأكثر)
1. **التسجيل**: الاسم ورقم الجوال، ثم رمز تحقق تجريبي (اضغط على الإشعار لتعبئته)، ثم إنشاء رمز المرور.
2. **إعداد الدخل**: ستة أسئلة (المعاش، المبلغ المستثمر، الدخل المطلوب، تقبّل المخاطر، يوم الدفعة)، وبعدها تظهر الخطة مع إقرار المخاطر لسلة النمو.
3. **الإيداع وتفعيل الخطة**.
4. **عرض الدفعات**: الدفعة القادمة، ومصادرها، وجدول 12 شهرًا، والسجل، وزر لمحاكاة استلام دفعة.
5. **تعديل الخطة**: الهدف الشهري، وتوزيع السلال ضمن حدودها، ويوم الدفعة، ووجهتها، وإيقافها مؤقتًا.

**صمّم خطتك بنفسك**: بعد عرض الخطة المقترحة، يقدر المتقاعد يختار أنواع المحافظ ووزن كل نوع (المجموع 100%)، ويتطلب إقرار مخاطر لو اختار محافظ عالية المخاطر. محفظة التقاعد تظهر تحت «إدارة المحافظ» وليست ضمن فئات أبيان.

**صكوك الشركات**: تستثمر فقط في صكوك شركات شرعية، بفرص محدودة المدة وعوائد ثابتة وتوزيعات دورية (شهرية، ربعية، نصف سنوية)، مع تفاصيل كل إصدار وجدول التوزيع القادم.

ومعها: الخدمات، وإنشاء محفظة (فيها المحفظتان الجديدتان **صكوك الشركات** و**الأسهم العقارية**)، وتفاصيل المحفظة، وحاسبة العوائد، وحاسبة الزكاة، وإدارة المحافظ، ودعوة صديق، والإعدادات، وإحصاءات النموذج.

**تجربة سريعة:** من شاشة البداية اضغط «تجربة سريعة بحساب أبو فيصل». رمز المرور لهذا الحساب: `111111`.

## النشر على GitHub Pages
1. ارفع محتوى المجلد إلى مستودع على GitHub (مثل `sanad-prototype`) في الفرع `main`.
2. من المستودع: **Settings** ← **Pages** ← **Source: Deploy from a branch** ← اختر `main` والمجلد `/ (root)` ثم **Save**.
3. بعد دقيقة أو دقيقتين يطلع لك رابط بصيغة `https://<اسم-المستخدم>.github.io/sanad-prototype/`.

الموقع ثابت بالكامل (HTML وCSS وJavaScript)، ولا يحتاج أي إعدادات بناء. ملف `.nojekyll` موجود حتى ينشر GitHub الملفات كما هي بدون Jekyll، والتنقل بين الشاشات يعتمد على `#` في الرابط فيشتغل من أي مسار فرعي.

## ملاحظات
- كل الأرقام والعوائد توضيحية وليست توصية استثمارية.
- لا يتم جمع أي بيانات أو تنفيذ أي عملية مالية. كل شيء يُحفظ في متصفح المستخدم فقط (localStorage).
- الصفحة معلّمة `noindex` (عبر وسم meta) حتى لا تظهر في محركات البحث.
- المستودع العام على GitHub يكون ظاهرًا للجميع، حتى لو الصفحة نفسها ما تظهر في البحث.
